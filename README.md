# أصالة المنتجات الأصلية

منصة مركزية لعلامات NFC: المدير العام يصدر دفعات العلامات للتجار، والتاجر يتابع مسحاته ومخزونه ومسابقته، والعميل يمسح العلامة فيتأكد إن المنتج أصلي.

تشتغل على Cloudflare Workers مع قاعدة D1. الصفحات ملفات ثابتة في `public/`، وكل مسارات `/api` تمر على الـ Worker.

## المرحلة الأولى: وش فيها

| الجزء | الرابط | المحتوى |
| --- | --- | --- |
| اللوحة الأم | `/admin/` | التجار، الحسابات، الدفعات وملف المصنع، البحث عن علامة، الإيقاف والتفعيل، الأكواد المزيّفة والبلاغات، التنبيهات، سجل العمليات |
| لوحة التاجر | `/merchant/` | المخزون مع توقّع موعد الخلوص، طلب علامات جديدة، المسحات حسب اليوم والمدينة، تشغيل المسابقة وإيقافها، تصدير المشاركات، إيقاف وتفعيل علاماته، البلاغات |
| صفحة التحقق | `/v/?t=...` | أصلي / مقلّد / موقوفة / جهاز آخر، بهوية التاجر، مع نموذج المسابقة ونموذج البلاغ |
| الدخول | `/login/` | دخول المدير والتاجر، و`/login/?setup` لإنشاء أول مدير عام |

## كيف تشتغل العلامات

- **الرابط موقّع:** كل علامة رابطها `/v/?t=<الدفعة>.<الرقم>.<توقيع>`. التوقيع 16 حرف من HMAC-SHA256 بالسر `TAG_SECRET`، فما يقدر أحد يخمّن رابط صحيح.
- **ما نخزّن الأكواد:** ملف المصنع يتولّد من التوقيع، فتقدر تنزّله أي وقت. وسجل العلامة في القاعدة ينشأ أول ما تنمسح أو تتوقف، فدفعة 100 ألف علامة هي سطر واحد في القاعدة.
- **الدفعة تُنشأ موقوفة** (`pending`)، وتفعّلها لما تُشحن.
- **ربط الجهاز:** العلامة ترتبط بأول جوال يمسحها، وجهاز ثانٍ مسموح خلال 10 دقائق فقط.
- **حد الفحوصات:** الافتراضي 5 لكل علامة، ويتغيّر لكل تاجر. الفحص اللي بعده يقفل العلامة (`auto_locked`).
- **الإيقاف:** التاجر يوقف ويفعّل علاماته، والمدير العام يوقف أي علامة، وإيقاف المدير ما يقدر التاجر يلغيه. إعادة التفعيل تصفّر عدّاد الفحوصات.
- **المخزون "الباقي"** = علامات الدفعات المفعّلة اللي ما انمسحت أبداً. أول مسح يعني إن العلامة انباعت.
- **التنبيهات** تشتغل كل ساعة (Cron): المخزون قارب يخلص أو خلص، وموجة أكواد مزيّفة (20 أو أكثر في اليوم). كل نوع يتكرر مرة كل 24 ساعة كحد أقصى. التنبيهات تظهر داخل اللوحة، والإيميل والواتساب في مرحلة لاحقة.

## النشر لأول مرة

```bash
npm install
npx wrangler login
npx wrangler d1 create asalah          # انسخ database_id الناتج إلى wrangler.toml
npm run db:migrate:remote
npx wrangler secret put TAG_SECRET     # 32 حرف عشوائي أو أكثر، احفظه، ولا تغيّره بعد أول دفعة
npx wrangler secret put SETUP_TOKEN    # 32 حرف عشوائي أو أكثر
npm run deploy
```

بعدها افتح `https://<الدومين>/login/?setup`، وأنشئ حساب المدير العام بمفتاح `SETUP_TOKEN`. هذي الصفحة تشتغل مرة وحدة فقط.

ربط الدومين: من Cloudflare ← Workers ← asalah-platform ← Settings ← Domains & Routes. وإذا كان رابط التحقق على دومين غير دومين اللوحات، أضف المتغير `VERIFY_ORIGIN` (مثل `https://verify.example.com`) عشان يطلع في ملف المصنع.

> **تنبيه مهم:** تغيير `TAG_SECRET` يبطل كل العلامات المطبوعة. احفظه في مكان آمن.

## التطوير والاختبار محلياً

```bash
cp .dev.vars.example .dev.vars
npm run db:migrate:local
npm run dev        # http://localhost:8787
npm test           # اختبارات التكامل (يشغّل نسخة محلية بقاعدة فاضية)
```
